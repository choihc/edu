Design Spec · 2026-05-19

AI Native 발표 슬라이드 — 디자인 스펙

사내 개발팀 대상 20~30분 발표. 핵심 메시지는 "AI Native는 도구의 교체가 아니라 운영체계의 교체". Anthropic 1차 자료(2025–2026)로 실증하고, Superpowers spec/plan + 멀티에이전트 운영을 사내 사례로.
대상 사내 개발팀 (FE/BE 시니어 포함) 분량 20~30분 · 25장 형식 React 라우트 /ai-native 톤 도발적 주장 + 실증

Executive Summary

① 운영체계의 교체 메시지를 5막 25장으로 누적 설득한다.

② 정량 데이터는 Anthropic 1차 자료로만 채운다 (Economic Index, How AI Is Transforming Work at Anthropic, 2026 Agentic Coding Trends, Demystifying Evals, AI Coding Skills).

③ 본인 팀의 Superpowers + 멀티에이전트 워크플로를 핵심 사례(Act 4)로 사내 차별화.

④ 기존 Presentation.jsx 패턴(슬라이드 데이터·키 네비·PDF/HTML export) 그대로 계승하여 운영 비용 최소화.

2.목표와 비목표

2.1 목표

  1. 메시지 전달 — "AI Native = 운영체계 재설계" 단일 결론을 5막 구조로 누적 설득
  2. 실증 기반 — 모든 정량 데이터는 Anthropic 1차 자료로 출처 명시
  3. 사내 차별화 — Superpowers spec/plan + 멀티에이전트 페르소나를 핵심 사례로
  4. 운영 일관성 — 기존 Presentation.jsx, MultiAgentProcess.jsx 패턴 그대로

2.2 비목표

  • AI/ML 모델 학습 알고리즘 강의 (튜토리얼 아님)
  • 벤더 비교 (Copilot vs Claude 등) — Anthropic 1차 자료로만
  • 인터랙티브 데모 — 정적 슬라이드만
  • 다국어 — 한국어 단일

3.대상과 톤

대상사내 개발팀(FE/BE 시니어 포함, AI 도구 경험 다양)
분량20~30분 (25장 내외)
톤도발적 주장 + 실증 — "AI 기능을 붙이는 것은 AI Native가 아니다"
언어한국어, 기술 용어는 한영 병기
디자인Presentation.jsx 톤 계승 (모던·컬러풀, 슬라이드 모드, 키보드 네비)

4.슬라이드 구성 (5막 25장)

ACT 0 Hook · 2장

#kind메시지 / 데이터
1title"AI Native: 도구의 교체가 아니라 운영체계의 교체"
2quote"AI 기능을 붙이는 것은 AI Native가 아니다. PDLC 전체를 다시 설계하는 것이다."

ACT 1 왜 지금 — 패러다임 · 4장

#kind메시지 / 데이터
3paradigm-shiftSoftware 1.0 → 2.0 → 3.0 (Karpathy) + Claude 모델 진화 타임라인 (Sonnet 4.6@2026.02, Opus 4.7@2026.04)
4claude-stat-gridAnthropic 내부 일일 업무 28%→59% · +50% 생산성 · PR merge +67% · 14% 파워유저 +100% · 연속 tool call 9.8→21.2 · 인간 turn 6.2→4.1
5claude-shiftAnthropic 6개월 추적 기능 구현 14%→37% · 코드 설계/계획 1%→10% · 27% "Claude 없으면 안 했을 일"
6definitionAI Native 4가지 조건: ①AI가 일할 구조 ②평가/관찰성 ③피드백 루프 ④인간은 검증·책임

ACT 2 무엇이 달라지는가 — 페르소나 · 5장

#kind메시지 / 데이터
7personas-grid5개 페르소나 카드(기획자/개발자/디자이너/조직장/경영진)
8persona-deep개발자 FE — 디버깅 55% / 코드 이해 42% / 구현 37%. 역할: 코드 작성자 → AI 시스템 오케스트레이터
9persona-deep기획자 — 기능 명세자 → AI 행동 설계자. KPI: 과업 성공률·재시도율·신뢰도·전환율
10persona-deep디자이너 — 화면 설계자 → Human-AI Interaction 설계자
11metric-tableEconomic Index 2026.03 고숙련자 성공률 +10%p · 개발자 Opus 사용률 34% — "학습 곡선이 KPI"

ACT 3 5단계 사이클 — 본체 · 7장

컨텍스트 → 실행 → 검증 → 반영 → 학습

#kind메시지 / 데이터
12cycle-overview5단계 다이어그램 (루프 시각화)
13cycle-step컨텍스트 — MCP(2024.11) + Spec Kit + Superpowers spec/plan. 사내: docs/superpowers/specs/ · plans/
14cycle-step실행 — Anthropic Building Effective Agents 5패턴: Prompt Chaining / Routing / Parallelization / Orchestrator-Workers / Evaluator-Optimizer
15cycle-step검증 — Eval-Driven Development. Anthropic Demystifying Evals 2026.01 코드+모델+휴먼 3-grader · pass@k vs pass^k · 20~50 task로 시작
16cycle-step반영 — 전수 리뷰 불가능. Evaluator-Optimizer 자동 게이트 + 위험 가중 리뷰
17cycle-step학습 — Anthropic AI Coding Skills AI 그룹 -17%p(50% vs 67%, p=0.01), 디버깅 능력 가장 큰 감소 → 학습 모드 + failure mode 라이브러리
18risk리스크 Productivity Panic(Bloomberg 2026.02) · 멘토십·온보딩 감소 · OWASP LLM Top 10 · EU AI Act · NIST AI RMF

ACT 4 본인 사례 — 핵심 차별점 · 4장

21case-multiagentPM · 디자이너 · 개발 3인조 (주작업/리뷰어/감독자). /multi-agent 발표와 연결

5.데이터 모델

5.1 슬라이드 데이터 (src/AiNativePresentation.jsx)

const slides = [
  { kind: "title", eyebrow, title, subtitle, tagline, desc },
  { kind: "quote", eyebrow, quote, attribution? },
  { kind: "paradigm-shift", stages: [...], timeline: [...] },
  { kind: "claude-stat-grid", source, stats: [{value, label, delta?}] },
  { kind: "claude-shift", source, rows: [{label, from, to}] },
  { kind: "definition", items: [{n, title, body}] },
  { kind: "personas-grid", personas: [{role, concern, shift, kpis}] },
  { kind: "persona-deep", role, shift, kpis, data?: [{label, value, source}] },
  { kind: "metric-table", source, rows: [[before, after, note]] },
  { kind: "cycle-overview", steps: [{n, label, oneLiner}] },
  { kind: "cycle-step", n, label, points, source?, sideNote? },
  { kind: "risk", items: [{title, body, source}] },
  { kind: "case-intro", title, body },
  { kind: "case-flow", nodes: [{label, tool, dir?}] },
  { kind: "case-multiagent", personas: [...], link },
  { kind: "case-lessons", lessons: [{title, body}] },
  { kind: "roadmap", phases: [{when, items}] },
  { kind: "references", groups: [{label, items: [{title, url}]}] },
  { kind: "closing", cta },
];
