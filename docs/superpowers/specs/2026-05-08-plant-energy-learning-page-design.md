# 12단원 식물과 에너지 학습 페이지 설계

## 배경

중학교 2학년 12단원 `식물과 에너지`의 주요 개념을 학생이 암기보다 이해 중심으로 학습할 수 있는 화면을 만든다. 광합성, 증산 작용, 식물의 호흡, 광합성과 호흡의 관계, 물과 무기 양분의 흡수 및 이동을 이미지와 애니메이션으로 연결해 보여준다.

기존 프로젝트는 Vite + React 기반의 단일 페이지 앱이며, 현재 `window.location.hash`를 직접 읽어 화면을 전환한다. 이번 작업에서 학습 페이지 추가와 함께 React Router를 도입해 해시 라우팅을 제거한다. 사용자가 명시적으로 해시 라우터 대신 라우터 라이브러리 채택을 요청했으므로 `HashRouter`가 아니라 History API 기반 라우팅을 사용한다.

## 목표

- `식물과 에너지` 개념을 낮과 밤, 식물 내부 구조, 조건 변화 실험의 흐름으로 이해하게 한다.
- 단원 학습 뒤 섹션별 확인 문제와 마지막 미니 테스트로 시험 대비를 돕는다.
- 기존 화면은 유지하면서 새 학습 페이지를 별도 경로로 추가한다.
- 수동 해시 라우터를 React Router 기반 라우팅으로 개선한다.

## 비목표

- 백엔드, 사용자 계정, 학습 기록 저장은 포함하지 않는다.
- 실제 교과서 이미지나 외부 이미지 의존성은 필수로 두지 않는다.
- 채점 결과를 서버에 저장하거나 누적 오답노트를 만들지 않는다.

## 사용자 경험

학습 페이지는 순서대로 배우는 코스형이다.

1. **낮과 밤 스토리**
   - 낮에는 광합성량이 호흡량보다 커서 겉으로는 이산화탄소 흡수와 산소 방출이 나타난다.
   - 밤에는 광합성이 멈추고 호흡만 계속되어 산소를 흡수하고 이산화탄소를 방출한다.
   - 빛, 잎, 기체 입자, 포도당 흐름을 움직이는 시각 요소로 표현한다.

2. **식물 내부 탐험**
   - 뿌리털, 물관, 체관, 잎, 엽록체, 기공, 공변세포를 한 식물 도식 안에서 연결한다.
   - 물과 무기 양분은 뿌리털에서 흡수되어 물관을 따라 위로 이동하고, 광합성 산물은 체관으로 필요한 곳에 이동한다.
   - 증산 작용은 기공을 통해 수증기가 빠져나가며 물 이동을 돕는 힘으로 설명한다.

3. **조건 실험**
   - 빛의 세기, 이산화탄소 농도, 온도, 습도를 조절하는 슬라이더를 제공한다.
   - 조건 변화에 따라 광합성 속도와 증산량이 어떻게 변하는지 즉시 보여준다.
   - 조건별 결과는 숫자보다 직관적인 게이지, 입자 움직임, 짧은 해설을 우선한다.

4. **시험 확인**
   - 각 섹션 끝에 1-2개의 확인 문제를 둔다.
   - 오답을 선택하면 왜 틀렸는지와 어떤 개념으로 돌아가야 하는지 짧게 알려준다.
   - 마지막에는 단원 미니 테스트를 제공해 광합성과 호흡 비교, 물질 이동 경로, 조건 변화 해석을 점검한다.

## 정보 구조

- 홈 화면에 `12단원 식물과 에너지` 메뉴를 추가한다.
- 새 경로는 `/plant-energy`로 둔다.
- 기존 화면은 아래 경로로 유지한다.
  - `/`: 홈
  - `/jp-vocab`: 일본어 단어 학습
  - `/multi-agent`: 멀티에이전트 개발 프로세스
  - `/spec-manager`: 스펙매니저 발표 자료
  - `/spec-manager/:slide`: 스펙매니저 발표 자료의 특정 슬라이드
- 기존 `#/...` URL로 접근하면 초기 진입 시 대응되는 새 URL로 `replaceState` 리다이렉트한다.

## 라우팅 설계

- React 18과 호환되는 `react-router-dom` 6.x 최신 안정 버전을 추가하고 `package-lock.json`도 갱신한다.
- `src/main.jsx`에서 `createBrowserRouter`와 `RouterProvider`를 사용한다.
- 기존 `window.location.hash` 기반 라우터는 제거한다.
- 기존 화면 이동 링크는 `#/...`에서 `/...`로 변경한다.
- 발표 자료 내부의 슬라이드 번호는 `/spec-manager/:slide` 경로 파라미터로 유지한다.
- 발표 자료에서 다음/이전/번호 이동을 하면 React Router navigate로 URL을 갱신한다.
- 정적 호스팅에서는 모든 앱 경로를 `index.html`로 돌려주는 fallback이 필요하다. 이번 코드 변경은 Vite 개발 서버와 Vite preview 기준으로 검증하고, 별도 정적 호스팅 설정은 배포 환경 작업으로 분리한다.

## 컴포넌트 설계

- `src/PlantEnergyLearning.jsx`
  - 학습 페이지의 주 화면.
  - 코스 진행 상태, 실험 슬라이더 값, 퀴즈 응답 상태를 관리한다.
  - 데이터는 파일 내부 상수로 정의해 구현 범위를 작게 유지한다.
  - 실제 외부 이미지 파일 대신 CSS 도형, 이모지, 간단한 SVG/HTML 도식, CSS 애니메이션으로 시각 자료를 구성한다.

- `src/main.jsx`
  - React Router 라우터 정의.
  - `/`, `/jp-vocab`, `/multi-agent`, `/spec-manager`, `/spec-manager/:slide`, `/plant-energy` 경로를 직접 연결한다.
  - 초기 진입 시 `window.location.hash`가 `#/...` 형식이면 대응하는 path로 치환한다.

- `src/App.jsx`
  - `HomePage`와 `VocabularyPage`를 named export로 노출한다.
  - 홈 메뉴에 학습 페이지 링크를 추가한다.
  - 기존 해시 링크를 일반 경로 링크로 전환한다.
  - 파일 내부 `useHash` 기반 분기와 기본 `App`의 해시 라우팅 책임은 제거한다.

- `src/MultiAgentProcess.jsx`
  - 스펙매니저 링크를 `/spec-manager`로 전환한다.

- `src/Presentation.jsx`
  - 해시 기반 슬라이드 번호 처리를 제거한다.
  - `useParams`, `useNavigate`로 슬라이드 번호를 읽고 갱신한다.

## 학습 콘텐츠 최소 기준

- 낮과 밤 스토리: 광합성 반응식, 호흡 반응식, 낮/밤 기체 출입 차이 설명을 포함한다.
- 식물 내부 탐험: 뿌리털, 물관, 체관, 엽록체, 기공, 공변세포, 미토콘드리아를 포함한다.
- 조건 실험: 빛 세기, 이산화탄소 농도, 온도, 습도 4개 조절값을 포함한다.
- 섹션 확인 문제: 낮과 밤 스토리, 식물 내부 탐험, 조건 실험 뒤에 각각 2문항씩 총 6문항을 제공한다.
- 단원 미니 테스트: 5문항을 제공한다.
- 모든 문항은 정답과 오답 피드백을 포함한다.

## 조건 실험 단순 모델

- 광합성 속도는 빛 세기와 이산화탄소 농도가 높을수록 증가하되 100에서 포화된다.
- 온도는 25도를 최적값으로 보고, 25도에서 멀어질수록 광합성 효율이 낮아진다.
- 증산량은 빛 세기와 온도가 높을수록 증가하고, 습도가 높을수록 감소한다.
- 이 모델은 정확한 생물학 계산식이 아니라 중학교 개념 이해용 단순 모델임을 화면 해설에 짧게 표시한다.

## 시각 및 상호작용 방향

- 색은 식물 단원에 맞게 잎 초록, 빛 노랑, 물 파랑, 에너지 주황을 사용하되 한 색 계열로만 치우치지 않는다.
- 첫 화면은 학습 도구 자체가 바로 보이게 만들고, 마케팅성 랜딩 페이지처럼 만들지 않는다.
- 애니메이션은 아래 목적에만 사용한다.
  - 광합성/호흡의 기체 출입 방향 표시
  - 물관/체관의 이동 방향 표시
  - 조건 실험 결과 변화 표시
- 모바일에서도 텍스트와 도식이 겹치지 않도록 그리드와 고정 비율 영역을 사용한다.

## 검증 기준

- `npm run build`가 통과해야 한다.
- 라우팅 변경 후 `/`, `/jp-vocab`, `/multi-agent`, `/spec-manager`, `/spec-manager/2`, `/plant-energy`가 렌더링되어야 한다.
- 기존 `#/jp-vocab`, `#/multi-agent`, `#/spec-manager/2` 접근 시 새 경로로 치환되어야 한다.
- 브라우저 뒤로가기/앞으로가기가 주요 라우트와 발표 슬라이드 이동에서 동작해야 한다.
- 새 학습 페이지에서 섹션 이동, 실험 슬라이더, 퀴즈 피드백이 동작해야 한다.
- 브라우저에서 데스크톱과 모바일 폭을 확인해 주요 텍스트와 시각 요소가 겹치지 않아야 한다.

## 리스크

- 해시 라우터 제거 시 정적 호스팅 fallback이 없는 배포 환경에서는 직접 URL 새로고침이 404가 될 수 있다. 배포 환경 설정은 별도 작업으로 관리한다.
- 기존 발표 자료의 슬라이드 번호 URL 동작은 `/spec-manager/:slide`와 legacy hash redirect로 유지한다.
- React Router 추가에는 의존성 설치가 필요하다.
- 한 화면에 시각 요소와 퀴즈를 모두 넣기 때문에 정보 밀도가 높아질 수 있다. 코스형 섹션과 진행 표시로 흐름을 유지한다.
