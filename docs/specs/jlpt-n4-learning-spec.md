## 1. 요약

이 웹페이지는 일본어능력시험(JLPT) N4를 준비하는 학습자가 1차 목록의 한자·어휘를 기억하고 문자·어휘 문제를 연습하도록 돕습니다.
학습자는 단어 안의 한자 읽기와 뜻을 회상하고, 정답 피드백을 통해 학습을 이어 갑니다.
실전 연습은 JLPT N4 문자·어휘의 다섯 문항 유형을 제공하며, 모든 문장·문항·선택지는 독자 창작합니다.
능동 회상, 정답 피드백, 간격 반복은 1차 사용자 요구인 '검색을 통해 한자·어휘를 가장 효과적으로 외우는 방법을 적용'하기 위한 근거를 반영합니다.

범위: 1차 목록 어휘 103개를 이용한 학습, 간격 반복 기반 복습 진도의 브라우저 저장, N4 문자·어휘 다섯 유형의 실전 연습입니다.

범위 밖: 문법·독해·청해 콘텐츠와 실제 청해 기능, 음성 재생, JLPT 공식 점수·합격 여부 산정, 사용자 계정과 다중 기기 동기화, 과거 학습·발표 콘텐츠입니다. 문법·독해·청해는 사용자가 확정한 향후 방향이지만 현재 범위에는 포함하지 않습니다.

| 용어 | 정의 |
|---|---|
| 1차 목록 | 사용자가 제공한 세 장의 이미지에서 식별한 N4 한자읽기 기출 어휘 103개입니다. 이미지의 편집·배열·설명을 서비스에 복제하는 뜻은 아니며, 어휘 자체(표기·읽기·뜻)는 사전적 사실 정보로만 사용합니다. |
| 학습 항목 | 1차 목록의 어휘 하나에 대응하는 학습 단위입니다. 표기·읽기·한국어 뜻·한국식 음훈·기억 힌트·예문을 가집니다. |
| 한국식 음훈 | 한자의 대표 의미를 한국어 한자음과 뜻으로 함께 나타낸 정보입니다. 예: 人 = 사람 인. |
| 혼동 후보 | 어떤 학습 항목의 오답 선택지로 쓰기에 적절한 다른 항목입니다. 읽기가 비슷하거나 한자 모양이 비슷한 항목을 뜻합니다. |
| 복습 예약 | 학습 항목별로 다음에 다시 물어볼 시각과 간격 단계를 함께 관리하는 상태입니다. |

## 2. 유저 시나리오

### S1. 학습 항목을 회상하며 학습한다 (P1)

**Given** 학습자가 공개 앱을 열고 학습을 시작한 상태입니다.

**When** 학습자가 카드의 질문에 네 선택지 중 하나로 답합니다.

**Then** 학습자는 정오답 피드백과 함께 단어 속 한자, 실제 단어에서의 읽기, 한국어 뜻, 한국식 음훈, 기억 힌트와 예문을 확인하고 다음 학습을 진행합니다.

관련 동작: JN4-002, JN4-003, JN4-004, JN4-005, JN4-006, JN4-007, JN4-008

### S2. 저장한 복습 진도를 이어 간다 (P1)

**Given** 학습자가 학습 또는 복습을 진행한 상태입니다.

**When** 학습자가 앱을 새로고침한 뒤 같은 브라우저에서 다시 엽니다.

**Then** 학습자는 저장된 복습 예약을 이어받아, 복습 시각이 된 항목부터 다시 학습합니다.

관련 동작: JN4-009, JN4-010, JN4-011, JN4-012, JN4-013, JN4-014, JN4-015

### S4. 학습 진도를 처음부터 다시 시작한다 (P2)

**Given** 학습자가 저장된 복습 진도를 가진 상태입니다.

**When** 학습자가 진도 초기화를 요청하고 확인합니다.

**Then** 학습자는 진도가 0으로 돌아간 것을 확인하고, 어휘 전체를 미학습 상태에서 다시 학습합니다.

관련 동작: JN4-037, JN4-038, JN4-039, JN4-040, JN4-041

### S3. 문자·어휘 실전 연습을 한다 (P1)

**Given** 학습자가 문자·어휘 실전 연습을 선택한 상태입니다.

**When** 학습자가 다섯 유형 중 하나를 선택하고 한 회차를 풀어 제출합니다.

**Then** 학습자는 정답 수, 문항별 정오답, 해설을 결과로 확인합니다.

관련 동작: JN4-016, JN4-017, JN4-018, JN4-019, JN4-020, JN4-021, JN4-022, JN4-023, JN4-025, JN4-026
